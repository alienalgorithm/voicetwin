# 英文读音预检（2026-11-24，轻度美化设计第 6 节第一阶段、统一计划 A8）

## 0. 结论

- V5 的英文读音全靠整合包里的 `GPT_SoVITS/text/english.py` 和 `en_normalization/expend.py`，英文没有 BERT 特征，读音标错了就一定读错。
  这些错是**确定的**（同样的文字每次都一样错），所以用程序在生成前、训练前查出来，不靠耳朵碰运气。
- 新文件 `voicetwin/backends/gsv_english.py`（只用 Python 标准库）：
  1. **只改发给引擎的那份文字**（`engine_text`）：能确定怎么改的几种写法自动改掉；字幕、查错字的参考文字、老师看到的文字都不变；
  2. **预检**（`precheck`）：列出可能读错的英文词，用老师看得懂的话说清楚会怎么读错、怎么改。
- 老师自带母本 `core_corpus.tsv`（1209 句，705 句有英文，2610 个英文词，371 个不同的）用 V5 自己的 english.py 实测：
  - 真的会读错：**AND ×10**（读成字母 EY1 EH1 N D IY1）、**live ×2**（「live 本身属于是不及物动词」，引擎读 L AY1 V，她要的是 /lɪv/）、**Dr.Banner ×1**（读成 D R AY1 V . B AE1 N ER0，「drive」+ 停顿）；
  - Dr.Banner 现在自动改成 Doctor Banner（实测改后 D AA1 K T ER0 B AE1 N ER0）；AND 和 live 列给老师看；
  - 全大写的缩写 AI ×2、VR ×5、PPT ×2 按字母读，这是对的，只在小结里提一句；
  - 1209 句里只有 Dr.Banner 这 1 句发给引擎的文字变了，其它 1208 句一个字都不改（旧缓存照常能用）。
- 老师词典（词 → 带重音的 ARPAbet，同时改训练和生成）**这次没做**，原因和下一步见第 5 节。

## 1. 依据：V5 的英文读音程序实际怎么做（读代码 + 真跑）

文件和 V5 整合包的大小一样（`research/gsv_v4_v5/官方资料/v5整合包/文件清单.tsv`）：english.py 9803 字节、expend.py 10879 字节、cmudict.rep 3731285 字节。
用 GitHub main 上的同样文件 + g2p_en 2.1.0（和整合包 `runtime_包版本.txt` 一样）真跑，结果全文在 `英文读音预检/实测结果.txt`（`英文读音预检/实测.py` 生成）。

| 引擎的做法（出处） | 后果（实测音素） | 程序怎么处理 |
|---|---|---|
| expend.normalize 最后一步 `re.sub(r"(?<!^)(?<![\s])([A-Z])", r" \1", text)`：词中间的每个大写字母前面加空格 | 全大写的词一个字母一个字母地读：AND → EY1 EH1 N D IY1；大小写混着的拆开读：McDonald's → Mc + Donald's（M IH0 K D AA1 N AH0 L D Z） | 预检：全大写、词典里也有这个单词的（AND）列为可能读错，建议写成小写；词典里没有的缩写（VR、AI、PPT）按字母读是对的，只提一句；拆开以后哪一段不在词典里才报 |
| `en_G2p.__call__`：`o_word == "A"` → EY1 | 句首的冠词 A 读成字母：A good student → EY1 G UH1 D … | 预检：大写 A 后面跟着小写英文词时报 |
| 词典：`read_dict_new`（cmudict.rep 第 57 行起 + cmudict-fast.rep）+ `hot_reload_hot`（engdict-hot.rep），删掉 AE AI AR IOS HUD OS；每个词只存第一个读音 | lead 总是 L EH1 D（铅）、live 总是 L AY1 V、wind 总是 W AY1 N D、tear 总是 T EH1 R…… | 预检：8 个这样的词（lead live wind wound tear bow bass sow）逐个实测过，写清楚引擎读哪个、读不出哪个 |
| g2p_en 的同形词按 NLTK 词性猜；object、rebel 两个读音是反的；english.py 自己改了 read | I object → AA1 B JH EH0 K T（名词读音）；an object → AH0 B JH EH1 K T；They rebel → R EH1 B AH0 L；He is a rebel → R IH0 B EH1 L；Please read it. → R EH1 D；I read books every day. → R IY1 D | 预检：object、rebel 说「名词、动词的读音是反的」；read 说按词性猜、单独提到和祈使句读 /red/ |
| `qryword`：词典里没有、只有首字母大写时查人名词典（namedict_cache.pickle）；不超过 3 个字母的按字母读；更长的拆词或神经网络猜 | 例如 Lv → EH1 L V IY1 | 预检：用整合包自己的词典（`load_dictionary` 读的词和 english.py 的 `_g2p.cmu` 完全一样：143199 个，实测）；人名词典是 pickle，只读 dict/list/str，里面引用任何类或函数就整个不读（不执行文件里的代码） |
| `_measurement_re` 把数字后面的 s 当成「秒」 | the 1990s → … N AY1 N T IY0 S EH1 K AH0 N D Z（nineteen ninety seconds） | 自动改：1990s → nineteen nineties（实测 N AY1 N T IY1 N N AY1 N T IY0 Z，和写成 nineteen-nineties 的音素完全一样）；1900s → nineteen hundreds、2000s → two thousands、2010s → twenty tens、’90s → nineties。别的「数字 + s」（10s 可能就是 10 秒）只提醒 |
| `text_normalize` 的 rep_map 键 `"[;:：，；]"`、`'["’]'` 经过 re.escape 只认字面的一整串，没生效；接着 normalize 删掉 `[^ A-Za-z'.,?!\-]` | otherwise; we → 没有停顿（AH1 DH ER0 W AY2 Z W IY1 …）；Note: this → 没有停顿；I’m → Im（IH1 M）；don’t → dont（D AA1 N T） | 自动改：英文后面的 ; : → 逗号（实测多出「,」停顿）；在句子最后的冒号 → 句号（GPT-SoVITS 把冒号当成已经有标点，不再补句号，删掉以后就没有结尾）；句子最后的分号不动（不算标点，引擎自己补「。」，本来就是句末的读法）；两边都是数字的（10:30、3:2）不动；英文词中间的弯引号 ’ → '（实测 I'm → AY1 M、don't → D OW1 N T） |
| 词典 dr = D R AY1 V；Mr. Mrs. Ms. No. U.S. a.m. vs. 里的点留着，变成句号 | Dr. Smith → D R AY1 V . S M IH1 TH；Mr. Smith → … ER0 . S …；No. 1 → N OW1 . W AH1 N；the U.S. government → Y UW1 . EH1 S . G … | 自动改：Dr. → Doctor；Mr./Mrs./Ms. → 去掉点（读音本来就对）；No. 1 → number 1；U.S. → U S（在句子最后时句号留着）；a.m. → A M（小写的 a 单独读是 AH0，所以写大写）；vs. → versus。e.g.、i.e. 引擎自己会换成 for example / that is，不动。St. 分不出是 Saint 还是 Street（引擎读 street + 停顿），只提醒 |

## 2. 实测：老师自带母本（`voicetwin/data/lexicon/core_corpus.tsv`）

用 V5 的 english.py 和词典跑（`英文读音预检/实测结果.txt` 第 1、2 节）：

| 词 | 几处 | 引擎实际的音素 | 程序怎么做 |
|---|---|---|---|
| AND（「AND的第二种连接方式」等） | 10 | EY1 EH1 N D IY1（字母） | 生成前列出来：建议写成小写 and，或者 lexicon.txt 加「AND => and」 |
| live（「live本身属于是不及物动词」） | 2（同一句） | L AY1 V | 列出来：引擎读 /laɪv/，读不出 /lɪv/（现在没法在这里选读法，第 5 节） |
| Dr.Banner（「You can call him Dr.Banner or Hulk.」） | 1 | D R AY1 V . B AE1 N ER0 | 自动改成 Doctor Banner：D AA1 K T ER0 B AE1 N ER0 |
| AI / VR / PPT | 2 / 5 / 2 | EY1 AY1 / V IY1 AA1 R / P IY1 P IY1 T IY1 | 按字母读是对的，小结里提一句 |

没有报的（实测读得对）：McDonald's ×2（M IH0 K D AA1 N AH0 L D Z）、JimWho ×1（JH IH1 M HH UW1）、lives ×5（「she lives in」，词典第一个读音 L IH1 V Z 就是动词）、does ×4。
母本里没有英文的 ; :、1990s、弯引号、Mr./No./U.S.，这些规则对现在的母本不起作用（测试里用别的句子各配了坏样本和好样本）。

和早先的调研报告（`调研_美化_english-pron.md`）比：LvMeng 和 lead to 在 11-24 更新母本以后已经不在了；live 是这次新找到的。

没有整合包词典时（例如测试环境）程序分不出全大写的是单词还是缩写，所以 AND、VR、AI、PPT 都报，拆开读的 McDonald's、JimWho 也都报，结果里如实写「没找到整合包的英文词典，这次没查词典里没有的词」。`tests/test_english_precheck.py::test_teacher_corpus_measured_findings` 在这种情况下核对上面的数。

## 3. 只改发给引擎的那份文字

- 改的地方：`GPTSoVITSBackend.synthesize` 和 `synthesize_many` 一进来就把请求的文字换成 `engine_text`（`_engine_req`），后面算能不能同时生成、复制几份、一个一个生成，用的都是改好的文字。别的引擎（`Backend.engine_text`）原样发。
- 不变的：字幕（`display`）、查错字用的参考文字（`seg.text`，语音识别听到 Doctor 多半写成 Dr.，用原文比更准）、结果表、老师在网页上看到的文字。
- 缓存：发给引擎的文字变了的句子，缓存键后面加一项 `engine_text=…`（「一模一样」的候选库 `pool_key` 也加）；没变的句子缓存键一个字节都不变（测试核对）。
- 报告：每句的 `engine_text`（只在改过时写）、整篇的 `english_precheck`（可能读错的、自动改好的、缩写、用了哪个词典）。
- 没改的：参考录音的文字（`prompt_text`）、训练用的文字（第 5 节）。

## 5. 没做的和下一步

1. **老师词典（词 → 带重音的 ARPAbet）**：没做。要同时安全地用在训练和生成上，至少要：
   - 生成：VoiceTwin 现在直接用整合包的 Python 运行 `api_v2.py`；要给 `text.english._g2p.cmu` 打补丁，得换成一个小启动器（先打补丁再 runpy 运行 api_v2），等于改推理服务的启动方式，要在老师的 V5 整合包和 Windows 上重新验证；
   - 训练：「一模一样」用 VoiceTwin 自己的 `get_text_mixed.py`，可以打补丁；标准方式用官方 1-get-text.py，也要包一层；
   - g2p_en 的同形词（read、object……）在查词典之前就决定了，只改 `_g2p.cmu` 对它们不起作用，还要改 `homograph2features`；
   - 词典的哈希要进缓存键和训练的素材指纹；训练标签变了要重新训练。
   所以这次只做「列出来 + 只改发给引擎的文字」，词典放到下一步，和上面几件一起做、一起测。
2. **英文后面的全角逗号「，」**：同一个 rep_map 的毛病（键 `"[;:：，；]"` 没生效），如果 LangSegmenter 把「，」分到英文段里，它也会被删掉。开发机上没有 split_lang / fast_langdetect，量不了「，」分到哪一段；老师的讲稿里「英文，」很多，改了会让很多句子的缓存失效、重新生成，所以先不改。下一步在 GitHub 上用真的整合包量一次。
3. 参考录音的文字（`prompt_text`）还没按 `engine_text` 改。
4. 训练用的文字不改（只列出来）。改了训练标签要重新训练，等老师词典一起做。
5. 单独提到的功能词（and → AH0 N D 的弱读）没处理。
6. **对声音的实际效果没听、没量**：这次改的是生成之前的文字，改后的音素是实测的，可 V5 模型按改后的音素读出来是不是更好，要在真的 V5 上生成对比（`gsv-v5-real` 工作流或者老师电脑）。

## 6. 测试

`tests/test_english_precheck.py`（48 个，不联网、不需要整合包）：

- 每种自动改的写法一个坏样本（必须改对，改第二遍不再变）和一组不该动的写法（10:30、3:2、中文冒号、句末分号、e.g.、Drive、No, I won't、10s、引号……）；
- 预检：没有词典 / 有仿真词典时各种情况（全大写的单词和缩写、拆开读、大写 A、多音词、词典里没有的、所有格、人名词典只查首字母大写、St.、10s）；
- 生成前 / 训练前给老师的话、最多列 6 个、没有要说的时候是空的；
- 整合包词典：从第 57 行读起、删掉的几个缩写、热词、人名词典里引用了类的 pickle 不读、文件改了重新读；
- 老师母本的实测数（第 2 节）；
- GPT-SoVITS 真正发出去的文字（单个生成、同时要好几个版本）、训练预览那一行（「一模一样」和标准方式）、网页点「生成」前的预检（读音词典改过的不再报）；
- 生成引擎：提醒、小结、报告、缓存键（没改的句子缓存键不变，改了的变，「一模一样」的候选库也变）；
- 网页：点「生成」后第一次更新就在结果区显示，后面不再重复发。

把 `_engine_req` 或缓存键那一项去掉，对应的测试会失败（实测过）。

## 7. 复现

```
NLTK_DATA=<nltk 数据> python -I research/V5极致/英文读音预检/实测.py <GPT-SoVITS 的 GPT_SoVITS 文件夹> <voicetwin 仓库>
```

需要 g2p_en 2.1.0、inflect、wordsegment、nltk（averaged_perceptron_tagger、cmudict 数据）；不需要显卡、不下载模型。
