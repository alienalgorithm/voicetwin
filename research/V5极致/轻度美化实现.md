依据：`research/V5极致/轻度美化设计.md` 第 2、3、4、7、8 节。这是可选功能，默认关（`synth.beautify.enabled: false`，网页勾选框默认不勾）。原声版本 A、B 一点不变。

## 1. 做了什么

## 2. 和设计不一样的地方（读代码、实测后改的，都有测试）

1. **强度 s 乘在整条链上**。设计只把 s 乘在 P(f) 上，那样有两个问题：
   - s = 0.25 时 C_her 还是满的，s = 0 时又一下子全部去掉；
   - 这和「s = 0 等于原声」「润色强度：一半」的说法对不上。

   现在 T = clamp(s·(C_her + P), ±2.5)。去齿音最多压 4·s dB，压缩最多压 3·s dB。高通在 s > 0 时一直开着。
2. **G5（对齐）改成和「base 只过静态 EQ」比互相关**，不直接和 base 比。
   - 原因：最小相位高通让很稳的基频超前（2 阶 Butterworth 本身就是最小相位，150 Hz 处约超前 30°）。
   - 实测：测试引擎的声音直接比互相关，滞后是 −11 和 −13 个采样，整体其实没有延迟。
   - 改了以后，正确的链是 0；晚 1 个或 3 个采样都能抓到（见测试 `test_alignment_gate_*`）。
3. **G6 每个频段的检查改成和「这条 EQ 按 base 自己的频谱应该带来的变化」比**，算法是 Σ P·|H|² / Σ P，C 和 base 用同样的说话帧。
   - 原因：直接拿频段中心的设计值比，100 Hz 附近几乎没声音的频段会差 0.6–0.7 dB。
   - 允许的误差 = 0.5 dB + 动态处理按设计最多能带来的变化：
     - 压缩是整体增益，任何频段最多 3·s dB；
     - 齿音带再加 4·s dB。
   - 只做线性 EQ 时实测偏差 ≤ 0.5 dB；+12 dB 搁架的坏样本照样被拒。
4. **G8（底噪）的上限是三个里最高的**：−60 dBFS、base、只过静态 EQ。
   - 原因：base 本来就有一点底噪时，开着空气感的 EQ 会把底噪抬高零点几 dB。按设计字面「不高于 base」，这样的句子永远过不了，整篇会白白减到 0（整篇实测时出现过）。
   - 这一关真正要抓的是压缩后调回响度把底噪抬高，设计的处理也是关掉这一句的压缩。现在就是这样：整篇测试里有底噪的两句关掉了压缩，C 通过。
5. **原声本来就在范围外的，不让它连累美化**：
   - G2 里「≥ min_pct」只要求原声本来达到 85% 的句子；
   - G7 里 base 本来就在她本人 p05–p95 之外时，只要求 C 不比 base 离得更远。

   不然原声自己的问题会让美化白白减到 0。
6. **校准文件不跟着合成模型走**。
   - 校准处理的是她的真实录音，结果只取决于三样：她的录音、声纹打分标准（`judge.signature()`）、处理链版本。
   - 所以这三样没变就直接读，变了才重做。设计写的是「每个新模型做一次」。
7. **去齿音的压低量按公式算准**：c = 10·log10(ρ(1−τ)/(τ(1−ρ)))，正好把比值压回阈值。全带里也有齿音带，只压「超出的 dB 数」会压不够。
8. **人声不到 2 秒的句子只做静态 EQ**。这样「只做了和全篇一样的音色润色」那句话（设计第 7 节的示例）才是真的。
9. **说话帧用能量阈值选**，和 `speech_level_db` 同一个算法，不用 silero-VAD。这样结果确定、不需要模型。「像你本人 %」的打分照旧用 VAD。
10. **错字没查时如实写原因**：「这次没有开识别校验」或者「识别模型这次用不了」。不写「错字没有增加」。

## 3. 实测的数（测试里都有，误差写在测试里）

**FIR**（4096 点最小相位，48 kHz）和设计目标的误差：

| 频段 | 最大误差 |
|---|---|
| 100 Hz 以上 | 0.07 dB |
| 56–100 Hz 余弦过渡区 | 0.21 dB（加上高通 0.30 dB） |
| 30–60 Hz（高通已经压了 5–16 dB） | 0.43 dB |
| 80 Hz–16 kHz 以外 | 0.013 dB |

**最小相位和「平方根」陷阱**：
- 冲激响应的主峰在第 0 个采样，前 2 ms 有 99% 以上的能量。
- 不按平方设计时，实测的 dB 正好只有一半（scipy 文档写的平方根陷阱）。

**G2 阈值**：按 μ = −0.1、σ = 0.9、N = 100 算是 −3.10 个百分点，和设计的推算一致。

**静音**：
- 逐句处理，停顿里非零采样 0 个。
- 同一条链在整篇上跑，停顿里非零采样超过 1000 个，自检会报错。
